# Pictures, and describing them

## Your library

Everything you upload goes to **Media library** and stays there. Any image field lets you either upload something new or pick something you already have, so the same photograph never needs uploading twice.

## The description field

Every picture asks what it shows. This is the field everybody skips and it is worth thirty seconds.

It is read aloud to anyone using a screen reader, it is shown if the image fails to load, and search engines use it. Write what somebody who cannot see it would need to know — not "image", and not the file name.

If a picture genuinely carries no information, tick **Purely decorative**. That hides it from screen readers, which is better than describing a texture.

## Sizes and placeholders

Upload something reasonably large — around 2000 pixels on the long edge is plenty — and let the site size it down. A 12-megapixel photograph straight off a camera makes your page slow for no visible gain.

The site automatically generates smaller copies for phones and derives an average-colour placeholder gradient for each photo, so pages load with zero layout shift (CLS: 0).

## Camera details (EXIF)

If you upload JPEG photographs from a dedicated camera, the site reads the technical camera details: camera body, lens, focal length, aperture, shutter speed, and ISO rating.

- **Private by default:** Camera settings are never shown publicly unless you explicitly enable the badge in the **Media library** by ticking **Show camera details publicly**.
- **No location data:** GPS coordinates and location tags are never extracted or stored.
- When enabled, an elegant camera badge appears beneath the photo or inside gallery cards.

## Galleries: Even Grid vs. Masonry

When arranging a **Gallery** block on your pages, you can choose between:

- **Even grid:** Crops items to a uniform, clean aspect ratio across columns.
- **Masonry:** Uses pure, responsive CSS multi-column masonry to preserve the original aspect ratios of portrait, square, and landscape photos together without cropping.
